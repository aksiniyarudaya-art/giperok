# Гиперок

Прототип платформы «Гиперок» (Минск): аренда спецтехники и грузоперевозки.

Внутри: лендинг, кабинет клиента, кабинет партнёра, CRM (менеджер, администратор, механик, кадровик) и PWA-приложение водителя. Данные демонстрационные.

## Запуск

```bash
npm install
npm run dev     # локально
npm run build   # сборка в dist/
```

Стек: React 19, TypeScript, Vite. Деплой: Vercel (настройки в `vercel.json`).
